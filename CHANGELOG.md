# Changelog

## [0.1.0] - 2026-09-07

### Added

- Modular terminal-native agent runtime
- Built-in skills and role-based agents
- Workspace, shell, Git, and filesystem mutation tools
- Permission policies and interactive approvals
- Mock and OpenAI-compatible providers
- Provider routing and failover
- Durable sessions and verification receipts
- JSON, JSONL, CI, and verification commands
- Initial package and distribution metadata
